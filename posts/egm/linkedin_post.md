🐘 What if forgetting was the feature, not the bug?

AI agents that remember your entire project are great for drafting specs, but that same memory makes them blind to their own assumptions. Nobody catches the gaps because everyone shares the same context.

Google's Elephant-Goldfish Model (EGM) fixes this with two kinds of agents:

✅ The elephant holds project context, requirements and earlier decisions, and drafts the specification
✅ Goldfish subagents review the draft with zero memory of the conversation, reading only the document and source material
✅ Fresh eyes surface missing assumptions, unclear requirements and implementation risks
✅ Skills for every stage: brainstorm, draft, review, resolve, bootstrap, review-loop, drift-report
✅ Works with Antigravity, Claude Code and Codex

Thousands of Google engineers already use it this way. 7,612 stars, Apache-2.0 licensed.

Install for Claude Code:
claude plugin marketplace add google/elephant-goldfish-model
claude plugin install egm@egm
