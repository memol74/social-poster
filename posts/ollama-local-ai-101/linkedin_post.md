🤖 What if your ChatGPT never left your laptop?

Most AI chat tools send every prompt to someone else's server, cost a monthly fee, and stop working the moment you lose internet.

Ollama is a free, open-source tool that runs a ChatGPT-style assistant entirely on your own machine:

✅ One command installs it on macOS, Linux or Windows
✅ ollama run llama3.2 downloads a ~2GB model and starts chatting, fully offline
✅ Pick your size: Llama 3.2 at ~2GB or Llama 3.1 8B at ~5GB
✅ OpenAI-compatible API on localhost:11434, so the OpenAI SDK works by just changing the base_url
✅ Add Open WebUI for a full browser-based chat interface

185,000+ GitHub stars. MIT licensed.

Install: curl -fsSL https://ollama.com/install.sh | sh
