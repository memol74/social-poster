🗺️ When did your architecture diagram last match your code?

Most diagrams are drawn once on a whiteboard, exported as a PNG, and go stale the week after.

Archify is an open-source agent skill that lets your coding agent build the diagram for you:

✅ Describe a system in one sentence ("Browser calls the API, the API checks Redis, a cache miss queries PostgreSQL") and get an interactive diagram
✅ Point it at a repository for a source-backed architecture map, with links back to the code
✅ Click any node, trace a path, highlight what sits downstream
✅ Ask a question and get a one-page explainer: conclusion first, then steps beside the diagram they walk through
✅ Everything ships as one standalone HTML file with light and dark themes, easy to share

89K+ GitHub stars, 130K+ installs, Apache-2.0. Works with Claude Code, Codex, Cursor and OpenCode.

Install: npx skills add tt-a1i/archify -g
