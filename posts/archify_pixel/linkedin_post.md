🗺️ Still drawing architecture diagrams box by box?

You describe the system in a meeting, someone opens a whiteboard tool, and twenty minutes later you have a diagram that's already outdated.

Archify is an open-source agent skill that turns any idea, plan, or codebase into an interactive diagram:

✅ Describe a system in one sentence, your agent draws it (e.g. "browser calls the API, API checks Redis, cache miss queries PostgreSQL")
✅ Point it at a real repository and it traces the architecture with source links pinned to a commit
✅ Click any node to open the full interactive view, trace everything downstream, or highlight a specific route
✅ Explainer mode answers a question as a one-page, source-cited report with tables, steps and diagrams
✅ Exports as one standalone HTML file, four styles, light or dark theme, plus PNG/WebP/JPG or PDF for explainer pages
✅ Works with Claude Code, Codex CLI, Cursor and OpenCode

89K+ GitHub stars, 130K+ installs on skills.sh, Apache-2.0 licensed.

Install: npx skills add tt-a1i/archify -g
